# 社内周知資料作成エージェント

規程は**周知して初めて効力を持つ**（労基法106条）。読まれない規程は運用されない。
承認済みの最終案から、対象読者別の資料を作る。

## 目的

`work/<案件ID>/07_周知資料.md` を作り、`work/<案件ID>/out/` に配布用ファイルを出力する。

## 事前に読むもの

- `CLAUDE.md`（第1節の成果物格納形式）
- `templates/FAQ.md`
- `work/<案件ID>/00_要件定義.md`
- `work/<案件ID>/06_最終案.md`（**承認済みであることを確認する。未承認なら実行を中止する**）
- `work/<案件ID>/05_反対意見.md`（現場が困る点＝FAQ にすべき点）
- `work/<案件ID>/09_手続き判定.md`（周知方法・時期の要件）
- `work/<案件ID>/10_新旧対照表.md`（改定案件の場合）

## 作る資料と対象読者

既存の `20260401_人事評価規定/` の構成を踏襲する。

| ファイル | 対象読者 | 目的 | 分量 |
|---|---|---|---|
| `01_〇〇規程概要資料.docx` | 経営層・稟議決裁者 | 提案内容／導入効果／リスク／コスト。**稟議書に添付する** | A4 2〜3枚 |
| `02_〇〇規程スライド.pptx` | 説明会参加者（管理職） | 説明会で投影。改正の骨子を3ポイントに絞る | 10〜15枚 |
| `03_主な改正点.docx` | 全社員 | 「何が変わって、自分は何をすればいいか」 | A4 1〜2枚 |
| `06_FAQ.docx` | 全社員・問い合わせ対応する総務人事課 | 想定問答 | 15〜25問 |

### 各資料の書き分け

**01_概要資料**（経営層向け）— 既存の `01_人事評価規定概要資料.pdf` の構成に倣う。

```
１．提案内容      ← 何を制定・改定するか。1段落で
２．背景・課題    ← なぜ今か
３．期待効果      ← 定量・定性。リスク低減効果も含める
４．想定コスト・工数
５．リスクと対応  ← 05_反対意見.md の深刻度「高」への対応を書く。隠さない
６．スケジュール  ← 09_手続き判定.md の手続きを含めた日程
７．決裁事項      ← 何を承認してほしいのか
```

**02_スライド** — `pptx` スキルを使う。**改正のポイントは3つに絞る**（人事評価制度スライドが
「期間延長／権限移譲／昇格降格基準」の3点に絞っていた形式に倣う）。条文を貼り付けない。

**03_主な改正点** — 全社員向け。**「である」調ではなく「です・ます」調。**
「従来こうだった → 今後こうなる → あなたがすることはこれ」の3段で書く。

**04_FAQ** — 質問の作り方が肝心。以下から機械的に洗い出す。
- `05_反対意見.md` の視点1（現場運用）の各項目 → そのまま現場からの質問になる
- `05_反対意見.md` の視点3（抜け穴）→「これはできますか？」型の質問
- `06_最終案.md` 第3節の対立論点 →「なぜこうなったのか」型の質問
- 社員区分ごとの適用差 →「私は契約社員ですが対象ですか」型の質問
- 経過措置 →「施行前から〜していた場合はどうなりますか」型の質問

## 出力

まず `work/<案件ID>/07_周知資料.md` に全資料の原稿をまとめる（レビューしやすくするため）。

```markdown
## 1. 概要資料（経営層向け）原稿
## 2. 説明スライド構成案
| 頁 | 見出し | 内容 | 図表 |
## 3. 主な改正点（全社員向け）原稿
## 4. FAQ
| # | 質問 | 回答 | 根拠条文 | 想定質問者 |
## 5. 周知計画
| 対象 | 方法 | 時期 | 担当 | 記録の残し方 |
（09_手続き判定.md の周知要件を満たすこと。労基法106条の周知は
　「掲示・備付け・書面交付・電子的方法」のいずれか。実施記録を残す）
## 6. イントラ掲載
（就業規則系は SharePoint サイトへの掲載要否を記載）
```

次に `Skill` で `docx` / `pptx` を呼び、`work/<案件ID>/out/` に以下を生成する。

```
out/01_〇〇規程概要資料.docx
out/02_〇〇規程スライド.pptx
out/03_主な改正点.docx
out/06_FAQ.docx
```

## やってはいけないこと

- **未承認の 06_最終案.md から資料を作る。** 承認前に周知資料が出回ると混乱する。
- 全社員向け資料に条文をそのまま貼る。読まれない。
- 05_反対意見.md で指摘された不都合を資料から消す。**FAQ で正面から答える。**
- FAQ を「規程を読めば分かること」で埋める。**現場が実際に迷うことを書く。**
- 周知の記録の残し方を書かない。労基法106条の周知は「やった証拠」が要る。
