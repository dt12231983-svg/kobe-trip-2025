# テンプレートディレクトリ

規程作成の各段階で使う書式のひな形。エージェントが参照する。
ルートの `CLAUDE.md`（体裁ルール・社員区分・2階層構造）が上位ルール。

## 2. テンプレートの位置づけ

**「空欄を埋めるフォーム」ではなく「判断材料つきの骨格」。**

各テンプレートには構造だけでなく、以下を必ず含める。

| 含めるもの | 理由 |
|---|---|
| **なぜその項目が要るのか** | 理由がないと省略される。例：「附則の施行期日がないと施行できない」 |
| **避けるべき書き方と、その直し方** | 悪い例だけ示しても直せない。対応表にする |
| **どの成果物から材料を取るか** | `05_反対意見.md` 第◯節 → FAQ の質問、のように出所を明示する |
| **作成上の注意** | 末尾に置く。エージェントが飛ばしがちな点を禁止形で書く |

エージェントがテンプレートを**そのままコピーして提出する**のを防ぐため、
プレースホルダは `〜` `〇〇` `◯` を使い、実在しそうな数値・固有名詞を入れない。

---

## 3. 体裁の一貫性

テンプレート内の条文例は、ルート `CLAUDE.md` 第4節の体裁ルールに厳密に従うこと。
**テンプレートが体裁を破っていると、そのまま成果物に伝播する。**

| 項目 | ルール |
|---|---|
| 条 | `第１条`（全角数字）、直前に `（見出し）` |
| 項 | 行頭に `２` `３`（全角）。第1項は番号なし |
| 号 | `①②③`、細分は `ア イ ウ` |
| 章 | `第１章　総　則`（字間を空ける慣行） |
| 用語 | **「規程」に統一**。「規定」は条文を指す場合のみ |
| 文体 | 規程本体は「である」調。**FAQ・周知資料のみ「です・ます」調** |
| 社員区分 | ルート `CLAUDE.md` 第3節の正式名称のみ。造語しない |

## 4. HD層の規程を扱う場合

名宛人の書き方が変わる。`規程ひな形.md` 末尾の HD 層向け記載例を使う。

```
第１条　本規程は、株式会社D＆Dホールディングス（以下「当社」という。）、当社子会社及び
　　　　当社関連会社（…以下「グループ」という。）における〜について定める。
```

**HD層の規程は EVGM 単独で制定・改廃できない。** 稟議書テンプレートも
EVGM 内の稟議ではなく HD への上申様式になる点に注意（`稟議書.md` 第4項）。

## 5. テンプレートを追加・変更するとき

- [ ] 参照するエージェントの「事前に読むもの」に追記したか
- [ ] 条文例がルート `CLAUDE.md` 第4節の体裁に従っているか
- [ ] プレースホルダに実在しそうな数値・固有名詞を入れていないか
- [ ] 「なぜその項目が要るのか」を書いたか
- [ ] 末尾に「作成上の注意」を置いたか
- [ ] 社内に既存書式がある場合、それに合わせたか（下記参照）

### 社内の既存書式を優先する

新しく書式を発明せず、社内にあるものに合わせる。

| 既存書式 | 場所 | 対応するテンプレート |
|---|---|---|

| 成果物セット（01概要／02スライド／03改正点） | `REG_ROOT/20260401_人事評価規定/` | `稟議書.md`、`07-comms` の出力構成 |
