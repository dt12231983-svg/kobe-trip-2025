## 使い方の注意

### 必ず入れる条

| 条 | 理由 |
|---|---|
| 目的 | 規程の解釈指針になる。争いになったときの拠り所 |
| 適用範囲 | **社員区分を明示する。** 「全社員」で済ませない。CLAUDE.md 第3節の正式名称を使う |
| 主管 | 誰が運用するのか。EVGM業務分掌表と整合させる |
| 規程の改廃 | 改廃手続きを規程自身に書いておく |
| 附則（施行期日） | **これがないと施行できない** |

### 状況に応じて入れる条

| 条 | 入れるべき場面 |
|---|---|
| 定義 | 解釈が分かれ得る用語を使う場合。既存規程と同じ定義にする（02-consistency の指示に従う） |
| 弁明の機会 | 社員に不利益を与える処分を定める場合。**手続保障がないと権利濫用と判断されやすい** |
| 記録及び保存 | 法令上の保存義務がある場合、または監査で証跡が要る場合 |
| 経過措置 | 既存の権利・状態に影響する場合。**不利益変更では特に重要** |
| 従前の規程の廃止 | 既存の規程・通達を置き換える場合。**書き忘れると二重に有効な規程が残る** |

### 避けるべき書き方

| 悪い書き方 | なぜ悪いか | 直し方 |
|---|---|---|
| 「原則として全社員に適用する」 | 例外が不明。現場が判断できない | 適用対象と適用除外を条で分けて明示 |
| 「必要に応じて〜することができる」 | 誰が何を基準に判断するのか不明 | 主語と判断基準を書く |
| 「速やかに届け出るものとする」 | 期限が特定されない | 「◯日以内に」と数値で書く |
| 「〜については別に定める」の多用 | 実質を先送りし、規程が空洞化する | 細則が必要なものだけに限り、03-drafter 第5節に列挙する |
| 「会社が認めた場合」 | 恣意的運用の余地。争いになる | 認める要件を号で列挙する |

### HD層の規程を書く場合

名宛人の書き方が変わる。CLAUDE.md 第2節を参照。

```
第１条　本規程は、株式会社D＆Dホールディングス（以下「当社」という。）、当社子会社及び
　　　　当社関連会社（当社、当社子会社及び当社関連会社と併せて、以下「グループ」という。）
　　　　における〜について定める。
```
